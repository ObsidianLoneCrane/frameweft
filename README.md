# FrameWeft

A local-first desktop toolkit for screen recording, video editing, and image editing.

FrameWeft is designed around three workspaces in one application. Record directly to a file, edit
videos imported from your computer, or prepare an image for a video project. Each workspace can
also be used on its own.

## Project status

FrameWeft is at the repository foundation stage. The product scope, architecture proposal, and
contribution workflow are documented. The desktop application, installers, and platform runtime
support are planned. Windows, macOS, and Linux are the target platforms.
